# VISUAL DNA FROM REFERENCE (Gamma: Glassmorphism)

## 1. 核心質感 (Core Aesthetics)
- **風格定位**: 高級 MMORPG 戰術儀表板 (Premium Tactical Dashboard)
- **材質特徵**: 毛玻璃透視 (Glassmorphism) 結合 琉璃暗金 (Obsidian Gold)
- **視覺深度 (Depth)**: 具備強烈的 3D 空間感，卡片懸浮於大氣層之上。

## 2. 環境與大氣 (Atmosphere & Environment)
- **背景 (Background)**: 極深的黑曜石色 (Obsidian/Slate-950)，接近純黑但帶有微弱的冷色調底蘊。
- **光源 (Lighting)**: 由底部向上發散的深紅色/血紅色環境光暈 (Ambient Red Glow)。
- **粒子系統 (Particles)**:
  - 類型：火花/餘燼 (Embers) 與 微弱金粉 (Gold Dust)。
  - 動態：隨機大小、透明度與向上飄浮的動態感，營造戰場硝煙與魔法氛圍。

## 3. 面板材質 (Panel Material - Glassmorphism)
- **底色 (Fill)**: 半透明深色 (例如 `rgba(15, 20, 25, 0.4)`)。
- **模糊 (Blur)**: 背景模糊 (Backdrop-filter: blur)，建議值 `12px` - `16px`。
- **邊框 (Border)**: 
  - 外部邊框：帶有微弱的琥珀金/香檳金漸層描邊 (例如 `rgba(212, 175, 55, 0.3)`)。
  - 頂部/高光：邊框的頂部通常會有較亮的高光反射，增強玻璃厚度感。
- **圓角 (Border Radius)**: 平滑且現代的圓角，建議值 `12px` 或 `16px` (非銳角)。
- **陰影 (Drop Shadow)**: 柔和的深色陰影，將卡片與背景抽離。

## 4. 色彩計畫 (Color Palette)
- **主色調 (Primary)**: 琥珀金 (Amber/Gold) - 用於標題、關鍵數字、圖示。
- **輔助色 (Secondary)**: 
  - 寶石紅 (Ruby/Crimson) - 用於寶石圖示、警示、強調色。
  - 冷灰/銀灰 (Slate/Silver) - 用於次要文字與輔助資訊。
- **文字 (Typography Colors)**:
  - 標題：亮金色或高對比白。
  - 內文：半透明白色 (`rgba(255, 255, 255, 0.7)`)。

## 5. 視覺裝飾 (Visual Embellishments)
- **角標/菲力格紋 (Filigree/Corners)**: 雖然是現代玻璃，但可能在角落有微小的金色裝飾點綴。
- **圖示 (Icons)**: 實心或帶有立體漸層的圖示 (如金幣、獎盃、寶石)。
- **徽章 (Emblems)**: 帶有強烈發光效果 (Glow) 與金屬質感的 3D 徽章。
